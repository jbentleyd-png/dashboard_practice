# dashboard_practice

Making a dashboard to practice using CSS grid.

Main takeways:

- CSS inheritance is powerful, and selection hinges on specficity.
- Specificity is not determined by whether an item has a specific class, but by how much detail is provided in he selector.
- relying on less inheritance-based selectors makes styling much easier (I styled the .top-section last, and the CSS slectors in that section are easier to read and to work with).
